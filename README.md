# CRX API Quickstart

The CRX API Quickstart pages of Discover and the CRX FIX API page, in Markdown. The taker and maker pages match the live Discover pages.

| File | Content |
|---|---|
| [taker-quickstart.md](taker-quickstart.md) | **Taker API Quickstart.** Request quotes, trade and read your book on CRX. |
| [maker-quickstart.md](maker-quickstart.md) | **Maker API Quickstart.** Open a 100 USD maker test trade and read it back. |
| [taker-script.py](taker-script.py) | The taker steps as one script. |
| [maker-script.py](maker-script.py) | The maker steps as one script, with more calls. |
| [fix/quickstart.md](fix/quickstart.md) | **CRX FIX API.** Trade FX non-deliverable forwards on CRX from a FIX 4.4 engine. The [Rules of Engagement](fix/rules-of-engagement.md), the dictionary [FIX44-CRX.xml](fix/FIX44-CRX.xml) and the sample messages in `fix/examples/` are beside it. |
| [fix/signature-proxy.md](fix/signature-proxy.md) | **CRX signature proxy.** The signature proxy is a small program that signs for the seat. |
| [llms.txt](llms.txt) | Index for LLMs. |

SDK: [crx-python](https://github.com/crxfoundation/crx-python). Blocks tagged `crx-*` are Discover page elements.
